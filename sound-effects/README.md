# Sound effects

Picked from [UI SFX](https://www.npmjs.com/package/uisfx) (npm package `uisfx` 0.4.0).
The audio is **CC0** (public domain): free for any use, including commercial,
no credit needed (see `LICENSE-AUDIO.txt`).

12 styles (one folder each), 5 sounds per style, as MP3:

| File | When |
|---|---|
| `record-start.mp3` | the mic starts listening |
| `recording-loop.mp3` | a quiet pulse while recording (loops) |
| `record-stop.mp3` | the mic stops |
| `correct.mp3` | a correct answer |
| `error.mp3` | a wrong answer |

Styles: minimal, soft, glass, arcade, mechanical, organic, dreamy, scifi,
rubber, cinematic, studio, zen.

Open `sound-effects/index.html` (e.g. http://localhost:8000/sound-effects/
with `start.command` running) to listen to them side by side.
